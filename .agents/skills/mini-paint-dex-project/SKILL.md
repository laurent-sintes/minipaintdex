# Piloter Mini Paint Dex

Lire `AGENTS.md`, déterminer l’intention courante, puis charger uniquement la référence nécessaire :

- développement, build ou tests : [`references/development.md`](references/development.md) ;
- démarrage ou redémarrage local : [`references/local-server.md`](references/local-server.md) ;
- commit ou push : [`references/git-delivery.md`](references/git-delivery.md).

Pour une administration de données, un import photo, un produit, une marque ou un dataset, basculer vers le skill `administer-minipaintdex-data`.

Ne jamais déduire l’autorisation Git d’un ancien message. `Go` autorise seulement le travail discuté. Un commit et un push exigent chacun une demande explicite dans le message courant.
