# Photos à importer

Déposez ici les photos des pots de peinture à analyser.

## Une photo exploitable

- photographier 4 à 8 pots à la fois ;
- placer les pots debout, étiquettes face à l’objectif ;
- utiliser une lumière diffuse et éviter les reflets ;
- cadrer assez près pour lire la marque, le nom et la référence ;
- préférer le format JPEG pour une compatibilité maximale.

Les fichiers traités seront ensuite déplacés dans un sous-dossier d’archive, sans être supprimés.
